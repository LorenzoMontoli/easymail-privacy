Easymail は、メールボックスをチャットのように表示する Android と iPhone 向けの無料メールクライアントです。Microsoft 365 の REST API である Microsoft Graph を通じて、OAuth 2.0 で Exchange Online に接続します。

直接接続。 メールは、暗号化された接続で端末と Microsoft の間でやりとりされ、Easymail のサーバーを経由することはありません。また、メールボックスの内容が私たちに送られることもありません。

コピーは端末上にだけ。 すばやく開きオフラインでも使えるよう、アプリはメールボックスのローカルコピーを上限付きで保持します。システムにより保存時に暗号化され、サインアウトまたはアンインストールで削除されます。

承認が必要な理由。 Microsoft の既定の同意ポリシーでは、ユーザーはサードパーティ製アプリにメールへのアクセス（Mail.ReadWrite）を許可できません。管理者が組織全体に対して一度承認します。

承認が済むと、ユーザーは Easymail を開き、「どのメールを使っていますか？」の一覧で「Outlook と Hotmail」をタップします（職場や学校のアカウントもこちらです）。あとはいつもどおり Microsoft でサインインします。この一覧はアプリの最初の画面です。別のメールボックスを追加するには、右上のイニシャルをタップしてから「アカウントを追加」をタップします。承認は Microsoft Entra の「エンタープライズ アプリケーション」でいつでも確認、取り消しができます。

有効にする設定はありません

Easymail は IMAP、POP、SMTP AUTH を使わないため、これらは無効のままでかまいません。Microsoft Graph はテナントのポリシーに従います。条件付きアクセスは通常どおり適用され、サードパーティ製アプリをブロックする EWS アプリケーション アクセス ポリシーは Easymail もブロックします。

プライバシー通知とサポートページに、Easymail の運営者と連絡先が書かれています。

조직에서 Easymail 승인하기

Microsoft 365, Exchange Online, 학교 테넌트의 IT 관리자를 위한, 1분이면 끝나는 절차입니다.

Easymail이란

Easymail은 메일함을 채팅처럼 보여 주는 Android와 iPhone용 무료 메일 클라이언트입니다. Microsoft 365의 REST API인 Microsoft Graph를 통해 OAuth 2.0으로 Exchange Online에 연결합니다.

무엇을 요청하며, 왜인가

위임된 권한만 사용합니다. Microsoft Graph의 Mail.ReadWrite, Mail.Send, User.Read, 그리고 다시 묻지 않고 토큰을 갱신하기 위한 offline_access입니다. 모든 작업은 로그인한 사용자를 대신해 그 사용자 자신의 권한으로 이루어집니다. 애플리케이션 권한은 없으며 다른 메일함, 일정, 연락처에는 접근하지 않습니다.

직접 연결합니다. 메일은 암호화된 연결로 휴대전화와 Microsoft 사이를 오가며 Easymail 서버를 거치지 않습니다. 메일함의 어떤 내용도 저희에게 전송되지 않습니다.

사본은 휴대전화에만 있습니다. 빠르게 열고 오프라인에서도 쓸 수 있도록 앱은 메일함의 로컬 사본을 용량 제한을 두고 보관합니다. 시스템이 저장 시 암호화하며, 로그아웃하거나 앱을 삭제하면 지워집니다.

승인이 필요한 이유. Microsoft의 기본 동의 정책은 사용자가 타사 앱에 메일 접근(Mail.ReadWrite)을 허용하는 것을 막습니다. 관리자가 조직 전체를 위해 한 번만 승인하면 됩니다.

contoso.com 또는 contoso.onmicrosoft.com. 비워 두면 Microsoft가 묻습니다.

켜야 할 것이 없습니다

Easymail은 IMAP, POP, SMTP AUTH를 사용하지 않으므로 이들은 꺼 두어도 됩니다. Microsoft Graph는 테넌트의 정책을 따릅니다. 조건부 액세스는 평소처럼 적용되며, 타사 앱을 차단하는 EWS 애플리케이션 액세스 정책은 Easymail도 차단합니다.
